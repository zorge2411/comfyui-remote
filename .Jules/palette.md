## 2024-05-23 - [Destructive Action Confirmation]
**Learning:** Users can accidentally delete workflows because the delete action was immediate.
**Action:** Always wrap destructive actions (like delete) in a confirmation dialog to prevent data loss.

## 2024-05-24 - [Form Input Usability]
**Learning:** Text inputs for generative AI prompts are typically long. Single-line inputs frustrate users who can't see their full prompt.
**Action:** Default to multiline (`minLines=3`) and provide a 'Clear' button for text inputs in prompt forms.

## 2024-05-24 - [Image Selection Visibility]
**Learning:** Full-image overlays for "edit" actions obscure user content, which is critical for verification (e.g., img2img inputs).
**Action:** Use unobtrusive corner badges or floating action buttons for edit indicators on image previews.

## 2024-05-25 - [Button Disabled States]
**Learning:** Users lack feedback when hitting limits on stepper controls (e.g. Batch Count).
**Action:** Use `enabled` parameter on `FilledIconButton` to visually disable actions when limits are reached.

## 2026-02-02 - [Gallery Accessibility]
**Learning:** Using static content descriptions (e.g., "Generated Media") for list items renders the gallery unusable for screen readers.
**Action:** Use dynamic content descriptions that include unique identifiers or metadata (e.g., "Generated by [Workflow] on [Date]") for list items.

## 2026-02-03 - [Destructive Action Consistency]
**Learning:** Inconsistent safety patterns (e.g., Gallery having delete confirmation while Queue does not) undermine user trust and muscle memory.
**Action:** Audit and unify destructive action behaviors across all screens to ensure a consistent safety model.
