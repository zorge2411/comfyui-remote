# Plan 89.1: Fixture Corpus and object_info Snapshot

## Objective

Commit a curated, license-clean set of real ComfyUI graph workflows and a matching sanitized `/object_info` snapshot, both produced by reproducible scripts. Plan 89.2's test harness runs on this data. See `89-CONTEXT.md` (D-01 to D-04).

<task type="auto">
  <name>Capture a sanitized object_info snapshot from stock ComfyUI</name>
  <files>
    scripts/corpus/export_object_info.py (new)
    app/src/test/resources/workflow-corpus/object_info.json (new, generated)
  </files>
  <action>
    Write `export_object_info.py` (Python 3, stdlib only):
    - `--url` (default `http://127.0.0.1:8188`): GET `{url}/object_info`.
    - `--fixtures DIR`: collect every `type` from the fixtures' top-level nodes and `definitions.subgraphs[*].nodes`. Skip subgraph UUID types and frontend-only types (Reroute, PrimitiveNode, Note, MarkdownNote).
    - Keep only those node types in the output.
    - Sanitize: for every input whose spec is `[[...options...], {...}]`, and whose options look like files (entries containing `.` plus a model extension such as safetensors/ckpt/pt/pth/bin/gguf/onnx, or any `/` or `\`), replace the options with `[]` and drop `default`. Keep static enum combos, e.g. `sampler_name`.
    - Write the result with sorted keys and 1-space indent, so diffs stay readable.
    - Print node-type count, the number of lists sanitized, and any fixture types missing from the server.
    Get a server to export from (D-03):
    - Preferred: shallow-clone `github.com/comfyanonymous/ComfyUI` into the scratchpad, pinned to the latest tagged release. `pip install` its `requirements.txt` with the PyPI torch wheel (download.pytorch.org is blocked here), then run `python main.py --cpu --listen 127.0.0.1 --port 8188`.
    - If the install fails or exceeds the disk budget: stop, and ask the user to run the script against their own server (`python scripts/corpus/export_object_info.py --url http://<server>:8188 --fixtures app/src/test/resources/workflow-corpus/workflows`), then commit the output.
    Never commit the ComfyUI checkout or the raw unsanitized dump.
  </action>
  <verify>python3 scripts/corpus/export_object_info.py --help; python3 -c "import json;d=json.load(open('app/src/test/resources/workflow-corpus/object_info.json'));print(len(d))"; grep -c -E '\.(safetensors|ckpt|pth|gguf)"' app/src/test/resources/workflow-corpus/object_info.json || true</verify>
  <done>`object_info.json` exists and holds every non-frontend node type used by the fixtures; the grep finds 0 model file names; the ComfyUI version or commit is recorded for MANIFEST.md.</done>
</task>
