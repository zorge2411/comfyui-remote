# Plan 90.2: Virtual Nodes (PrimitiveNode, Reroute, Set/Get, Notes) and Promoted Socket Targets

## Objective

Never send editor-only nodes to the server; resolve them the way the frontend does:
- PrimitiveNode values become literal target values;
- Reroute and other virtual nodes pass through the same-slot input;
- GetNode resolves through the SetNode with the same name;
- Note and MarkdownNote are skipped.

Also finish Phase 93's promoted-widget behaviour for socket targets (D-03 to D-05). This clears the last corpus known failures (the Milestone 4 must-have) and the 29 C7 across templates.

**Depends on**: Plan 90.1 (the virtual-node hops use the new `resolveRealSource(link, targetType)`)
