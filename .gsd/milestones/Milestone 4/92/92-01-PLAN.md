# Plan 92.1: ServerErrorReport Parser and Formatter

## Objective

One pure-Kotlin parser for everything the server says when a prompt fails: validation (400), partial acceptance (200 with `node_errors`), and runtime `execution_error`. It produces a per-node report with titles and every reason, plus a readable formatter (D-01, D-02).

## Context

- .gsd/phases/92/92-CONTEXT.md
- ComfyUI `server.py` `post_prompt`; `execution.py` `validate_prompt`, `validate_inputs` (error dict shape), `handle_execution_error`

<task type="auto">
  <name>domain/ServerErrorReport.kt</name>
  <files>app/src/main/java/com/example/comfyui_remote/domain/ServerErrorReport.kt (new)</files>
  <action>
    Types:
    - `data class ServerErrorReport(val summary: String, val nodes: List<NodeError>, val isPartial: Boolean = false)`;
    - `NodeError(nodeId, classType, title, errors: List<Reason>)`;
    - `Reason(inputName: String?, message: String, details: String?)`.
    Companion functions:
    - `fromPromptError(httpCode: Int, body: String?, sentPrompt: JsonObject?)`:
      - reads `error.message` (summary) and `node_errors`;
      - `inputName` comes from `extra_info.input_name`;
      - if `node_errors` is empty, the summary includes `error.details` when present;
      - an unparseable body gives "HTTP {code}" plus the first 500 characters of the body.
    - `fromPartialAcceptance(nodeErrors: JsonObject?, sentPrompt)`: returns null when empty; otherwise `isPartial = true` with the summary "Some outputs were skipped by the server".
    - `fromExecutionError(data: JsonObject, sentPrompt)`: one node with the reason `"${exception_type}: ${exception_message}"`, summary "Execution failed".
    Titles come from `sentPrompt[nodeId]._meta.title`, falling back to `class_type`, then to "Node {id}".
    `format(): String`:
    - the summary line;
    - per node, a blank line and "Title (ClassType #id)", with "(ClassType)" omitted when the title equals the class type;
    - per reason, "• input: message — details". Omit details when they're blank or equal to the input name, and cut them at the first newline for per-node lines. Omit "input: " when the input name is null.
    Keep node order from the server response.
