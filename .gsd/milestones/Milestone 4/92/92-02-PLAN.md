# Plan 92.2: Show Server Errors Everywhere They Happen

## Objective

Use `ServerErrorReport` wherever the app talks to `/prompt` or hears about execution:
- the form's Generate path shows all validation errors;
- partial acceptance becomes visible;
- runtime `execution_error` gets a message;
- local-queue failures keep and show their reason (D-03 to D-06).

**Depends on**: Plan 92.1

## Context

- .gsd/phases/92/92-CONTEXT.md
- app/src/main/java/com/example/comfyui_remote/MainViewModel.kt, QueueViewModel.kt
- app/src/main/java/com/example/comfyui_remote/network/ComfyApiService.kt (`PromptResponse`)
- app/src/main/java/com/example/comfyui_remote/data/LocalQueueItem.kt, AppDatabase.kt; ui/QueueScreen.kt
- app/src/main/java/com/example/comfyui_remote/ui/components/ErrorCard.kt, ui/DynamicFormScreen.kt

    - `DynamicFormScreen`: pass `onCopy` for the execution error card, and show `_serverWarning` in a warning-coloured card ("Some outputs were skipped", dismissible).
