# Plan 93.1: Match Subgraph Instance Inputs by Name

## Objective

Links into a subgraph instance currently reach the wrong interior input whenever the instance's serialized `inputs` array doesn't line up position-by-position with the subgraph's inputs. This happens in 136 of 293 instances across the official templates. Fix it by resolving each instance slot to its subgraph input the way the frontend does (D-01 in `93-CONTEXT.md`).
