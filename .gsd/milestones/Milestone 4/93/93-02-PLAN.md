# Plan 93.2: Apply Promoted Widget Values from Subgraph Instances

## Objective

When a subgraph input is shown as a widget on the instance and nothing is linked to it, ComfyUI uses the **instance's** value. The converter uses the interior node's own stored value instead, so the app can send a different prompt, seed or size than ComfyUI shows. In the templates, 61 of 788 promoted values differ, including the corpus fixture `image_mage_flow_t2i_int8` (prompt and seed). Apply the instance values as the frontend does (D-02 to D-05 in `93-CONTEXT.md`).

**Depends on**: Plan 93.1 (uses the same per-wrapper slot map to know which subgraph inputs are externally linked)

## Tasks

<task type="auto">
  <name>Compute promoted values during expansion and apply them in Mode B</name>
  <files>app/src/main/java/com/example/comfyui_remote/domain/GraphToApiConverter.kt</files>
  <action>
    **During expansion**, for each wrapper instance:
    1. Walk `definition.inputs` in order. An input is promoted when the first of its `-10` links (in `linkIds` order) whose target is an interior node points at an input slot that has a `widget` property. Record `(subgraphInputIndex, widgetName on each target)` for every target of that input.
    2. Take the instance's `widgets_values` (JsonArray only; ignore the dict form) and assign entries by position to the promoted inputs.
    3. Override from `properties.proxyWidgetErrorQuarantine` entries whose `originalEntry[0] == "-1"`, matching by input name.
    4. Skip any subgraph input that an external link feeds (use the Plan 93.1 slot map) or that has no value.
    5. For the remaining inputs, write `{widgetName: value}` into a `"__promoted_widgets"` JsonObject on each **remapped interior target node**, merging with any existing entries.
    **In Mode B**, when a key has an entry in the node's `__promoted_widgets` and the slot has no resolved link:
    - still call `findNextCompatibleWidget(key)`, so the `widgets_values` position is consumed and later widgets stay aligned;
    - use the override value, passed through `resolveComboValue`.
    Never emit `__promoted_widgets` into the API JSON; it lives only on graph nodes.
    Avoid rewriting interior `widgets_values` by index; widget order is Mode B's job.
  </action>
  <verify>Plan 93.2 tests below; `./gradlew testDebugUnitTest` (Windows: `gradlew.bat`)</verify>
  <done>An unlinked promoted input sends the instance's value. An externally linked one sends the link. An empty instance `widgets_values` keeps the interior values.</done>
</task>
