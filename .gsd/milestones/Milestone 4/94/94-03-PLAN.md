# Plan 94.3: App Form Support for V3 Combos and Dynamic Sub-Inputs

## Objective

After Plan 94.2, converted prompts contain dotted sub-inputs and V3 `COMBO` values. Make the generation form show these correctly:
- V3 combos (top-level and sub-inputs) become dropdowns instead of free text;
- dotted fields get their metadata through the selected option;
- the dynamic combo key is not offered as an editable field, since changing it would produce a prompt the server rejects (D-04).

**Depends on**: nothing in code (independent of Plan 94.2); its tests use dotted keys as Plan 94.2 emits them.
