# Plan 95.2: Named Widget Values and Defaults for Newer Widgets

## Objective

Use `widgets_values_named` when a node has it: it's keyed by widget name, so it survives node definitions that changed after saving. When a widget has no saved value at all, send the default the frontend would give it rather than leaving a required input out (D-03, D-04). Then measure the whole template set.

**Depends on**: Plan 95.1 (both change the same widget cursor logic in `emitInput`)

    - STRING: `default ?? ""`;
    - BOOLEAN: `default ?? false`;

    - dynamic combo: `default` or the first option key, then expand that option as in Phase 94.
    Log each default used with `CONVERT_DEBUG`.
    In `ApiPromptValidator.FILE_VALUE`, add `glb`, `gltf`, `fbx`, `obj`, `ply`, `stl`, `usdz`, `spz`, `splat` (D-05).
    Avoid:
    - defaults for sockets or linked inputs;
    - letting named values override a resolved link.
