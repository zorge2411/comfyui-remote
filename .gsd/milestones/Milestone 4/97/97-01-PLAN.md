# Plan 97.1: Keep Model Links at Import

## Objective

Keep each workflow's model download links (`properties.models` entries) when it is imported, and store only those the converted prompt actually uses. Also provide a pure-Kotlin check for which of them are missing on the server. This is the data the Plan 97.3 download UI needs.

  <action>
    `data class ModelSource(val name: String, val url: String, val directory: String)`.

    `object ModelSources`:
    - `extract(graphJson: String): List<ModelSource>`:
      - reads `properties.models` from every entry in `nodes`, from nodes in `definitions.subgraphs[].nodes`, and from the top-level `models` array;
      - skips entries with a blank `name`, `url` or `directory`;
      - removes duplicates by `directory + "/" + name`, keeping the first;
      - on invalid JSON, returns an empty list instead of throwing.
    - `usedBy(sources, promptJson: String)`: keeps the sources whose `name` equals the base name (text after the last `/` or `\`) of any string input value in the API prompt. A muted or removed loader then doesn't produce a download row.
    - `missing(sources, available: Map<String, List<String>>)`: returns the sources whose directory has a list and whose name is in it neither as the full name nor as the base name of an entry (server lists include subfolders, e.g. `flux/x.safetensors`). A directory with no list is treated as unknown, and its sources are not returned.
    - `toJson(list)` / `fromJson(text?)` with Gson. `fromJson` returns an empty list for null or invalid text.

    Tests:
    - `flux_schnell.json` → the expected checkpoint entry;
    - a corpus fixture with subgraph models (pick one with `grep -l '"models"'` whose models sit inside `definitions`) → those entries found;
    - inline cases: a top-level `models` list, duplicates, a missing url, `usedBy` dropping an unused entry, `missing` matching a subfolder entry, a directory with no list returns nothing, and a toJson/fromJson round trip.

    AVOID: reusing `WorkflowNormalizationService.extractModels`. It guesses from input names and has no URL or folder data.
