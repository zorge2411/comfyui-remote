# Plan 97.2: Companion Server Extension `comfyui_remote_helper`

## Objective

Write a small ComfyUI custom node, kept in this repo, that downloads a model from Hugging Face or GitHub straight into the right server models folder when the app asks. It reports progress over ComfyUI's websocket, supports cancelling, and uses `HF_TOKEN` for gated models. Core ComfyUI has no such endpoint, and ComfyUI-Manager rejects most template models or refuses over the network (see 97-RESEARCH.md).

    - `PICKLE_EXTS = {".ckpt", ".pt", ".pth", ".bin"}`.
    - `class RequestError(Exception)` with `status` (400, 403 or 409) and a readable `message`.
    - `validate_url(url)`: https only; the host is exactly one of the allowed hosts.
    - `validate_filename(name, allow_pickle)`:
      - rejects an empty name, `/`, `\`, `:`, `..` or a leading `.`;
      - the extension (lower-cased) must be in SAFE_EXTS, or in PICKLE_EXTS when `allow_pickle` is true;
      - otherwise a 403 that names `REMOTE_HELPER_ALLOW_PICKLE`.
    - `resolve_target(directory, filename, folder_map, exists)`:
      - `folder_map` is a dict from name to a list of paths, injected from `folder_paths.folder_names_and_paths`;
      - the directory must be a key with at least one path, and must not be `custom_nodes` or `configs`;
      - returns `os.path.join(paths[0], filename)`;
      - returns 409 when `exists(path)` is true.
    - `validate_request(body, folder_map, exists, allow_pickle)` → `(url, target_path)`.

    `test_validation.py` (unittest) covers:
    - http rejected; other hosts rejected, including `huggingface.co.evil.com`;
    - path traversal and subfolder names rejected;
    - `.ckpt` rejected unless allowed;
    - an unknown directory rejected;
    - an existing file gives 409;
    - a valid request resolves to the first folder path.

<task type="auto">
  <name>Routes and downloader</name>
  <files>
    server/comfyui_remote_helper/__init__.py (new)
    server/comfyui_remote_helper/downloader.py (new)
  </files>
  <action>
    `__init__.py`:
    - exports `NODE_CLASS_MAPPINGS = {}` and `NODE_DISPLAY_NAME_MAPPINGS = {}`;
    - registers routes on `server.PromptServer.instance.routes` (the core also serves them under `/api`):

    | Route | Behaviour |
    |---|---|
    | `GET /remote_helper/info` | `{"version": "1", "hf_token": bool(HF_TOKEN)}` |
    | `POST /remote_helper/models/probe {url}` | `validate_url`, then HEAD with redirects allowed and the token for huggingface.co. Returns `{"size": int or null, "gated": status in (401, 403)}`. Size comes from `x-linked-size` or `content-length` of the final response. |
    | `POST /remote_helper/models/download {url, directory, filename}` | `validate_request`. Also 409 when the same target is already queued. Queues the job and returns `{"id"}`. A `RequestError` becomes a JSON `{"error": message}` with its status. |
    | `GET /remote_helper/models/downloads` | Every job: `{id, filename, directory, total, done, status, error}`. `status` is queued, downloading, done, error or cancelled. |
    | `POST /remote_helper/models/downloads/{id}/cancel` | Cancels the job. |

    `downloader.py`: one asyncio worker on ComfyUI's loop, processing jobs one at a time (FIFO).
    - Stream with `aiohttp.ClientSession` (`timeout=ClientTimeout(total=None, sock_read=60)`) in 1 MiB chunks to `target + ".part"`.
    - Send `Authorization: Bearer $HF_TOKEN` only when the original host is huggingface.co.
    - On 401 or 403, fail with: "Gated model: accept its licence on huggingface.co and set HF_TOKEN on the server".
    - Before writing, when the size is known, check that `shutil.disk_usage(dir).free` is at least size + 1 GiB, and fail with a readable message otherwise.
    - When finished, `os.replace` the part file onto the target.
    - On error or cancel, delete the part file.
    - Progress: `PromptServer.instance.send_sync("remote_helper.download", job_dict)` at most once per second while downloading, and always on every status change.
    - Log with the `logging` module, prefixed `[remote_helper]`.

    AVOID: `requests` or other blocking I/O on the event loop, because it would stall ComfyUI's server.
    AVOID: writing directly to the target, because a half-written model would pass the app's "is it on the server" check.
  </action>
