# Plan 97.3: Download Missing Models from the App

## Objective

The workflow screen lists the models the workflow needs that aren't on the server. Each one can be downloaded to the server through the companion extension, with a confirm step, live progress and cancel. When the extension isn't installed, the app offers the link instead. Finished downloads clear the pre-flight warnings.

  <action>
    `ComfyApiService`:
    - `getHelperInfo()` for `GET remote_helper/info`, returning `JsonObject`;
    - `probeModel(@Body JsonObject)`, `startModelDownload(@Body JsonObject)`, `getModelDownloads()`, `cancelModelDownload(@Path id)`.
    - Start returns `retrofit2.Response<JsonObject>`, so the app can read the `{"error"}` body on 400, 403 or 409.

    `MainViewModel`:
    - `helperAvailable: StateFlow<Boolean?>`:
      - null means unknown;
      - set in the CONNECTED branch of the `connectionState` collector, next to `fetchNodeMetadata()`: true on success, false on HTTP 404 or any other failure;
      - also call `getModelDownloads()` there to restore running jobs.
    - `data class ModelDownload(id, filename, directory, total: Long?, done: Long, status: String, error: String?)` and `downloads: StateFlow<Map<String, ModelDownload>>`, keyed by `directory/filename`.
    - `suspend fun missingModels(workflow): List<ModelSource>`:
      - `ModelSources.fromJson(workflow.modelSources)`;
      - fetch `getModels(dir)` for each directory into a per-directory cache, `MutableMap<String, List<String>>`. On failure, leave the folder out, so it counts as unknown;
      - then `ModelSources.missing(...)`.
    - `suspend fun probeModel(source)` → `Pair<Long?, Boolean>`, or null on failure.
    - `fun downloadModel(source)`: POST; on error, `reportError(message from body)`.
    - `fun cancelModelDownload(id)`.
    - `handleMessage`: a new `"remote_helper.download"` branch parses `data` into `ModelDownload` and updates `downloads`. On `done`, remove that directory from the model cache, call `fetchNodeMetadata()`, and bump `modelsVersion: StateFlow<Int>` so the screen recomputes.

    AVOID: calling Manager routes; that was decided against in research.
    AVOID: polling while the websocket is connected. Poll only on reconnect.
  </action>
  <verify>gradlew.bat assembleDebug</verify>
  <done>Compiles. The view model exposes `helperAvailable`, `downloads`, `missingModels`, `probeModel`, `downloadModel` and `cancelModelDownload`.</done>
