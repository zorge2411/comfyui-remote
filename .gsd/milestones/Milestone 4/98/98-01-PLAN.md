# Plan 98.1: Check File Values Against Empty Server Lists

## Objective

Make the pre-flight check report a missing input file when the server's list for that input is empty. Today an empty list suppresses the check, so a workflow naming a video the server doesn't have goes straight to the server and fails (98-CONTEXT.md).

## Context

- .gsd/phases/98/98-CONTEXT.md
- app/src/main/java/com/example/comfyui_remote/domain/PromptValidator.kt (list check, around lines 141-150; `FILE_VALUE`)
- app/src/main/java/com/example/comfyui_remote/domain/GraphToApiConverter.kt (`comboOptions`, around line 1060)
- app/src/test/java/com/example/comfyui_remote/domain/PromptValidatorTest.kt
- app/src/test/java/com/example/comfyui_remote/domain/corpus/ApiPromptValidator.kt (calls with `checkFileValues = false`)

  <action>
    In `PromptValidator.kt`:
    1. Add a private helper `isUploadInput(spec: JsonArray)`. It returns true when `spec[1]` is an object with `image_upload`, `video_upload` or `audio_upload` set to true. It covers both the legacy `[[files], {...}]` form and the V3 `["COMBO", {...}]` form.
    2. In the list check, compute:
       - `isUpload = isUploadInput(spec)`;
       - `fileLike = isFile || isUpload`.

       Report when all of these hold:
       - `text !in options`;
       - `options.isNotEmpty() || (fileLike && checkFileValues)`;
       - `checkFileValues || !fileLike`.
    3. Messages. Every `fileLike` issue is `Severity.ERROR` with `Kind.VALUE_NOT_IN_LIST`:
       - non-empty list: unchanged, `File not on the server: '$text' not in [$shown]`;
       - empty list: `File not on the server: '$text' (the server has none for this input)`;
       - for upload inputs, append `; pick another file or upload it`.
    4. Non-file values keep their current warning. Update the KDoc on the object to mention the empty-list rule.

    Tests in `PromptValidatorTest` (existing `obj` style). Add a small `objectInfo` with:
    - `LoadVideo`: `file: ["COMBO", {"options": [], "video_upload": true}]`, output `["VIDEO"]`;
    - `LoadImg`: `image: [[], {"image_upload": true}]`, output `["IMAGE"]`;
    - `Pick`: `mode: ["COMBO", {"options": []}]`, output `["INT"]`;
    - one output node consuming them.

    Cases:
    - `gan_input.mp4` on LoadVideo → one VALUE_NOT_IN_LIST, ERROR, message contains `gan_input.mp4` and `upload`;
    - a legacy empty image list with `example.png` → ERROR;
    - `Pick.mode = "fast"` → no issue;
    - with `checkFileValues = false` → no issues;
    - the existing missing-checkpoint test still gives the old "not in [...]" message.

    AVOID: dropping the `options.isNotEmpty()` guard for every value. Dynamic combos with empty lists would give false warnings.
    AVOID: touching `ApiPromptValidator`. It passes `checkFileValues = false`, so the test-suite results must not change.
  </action>
