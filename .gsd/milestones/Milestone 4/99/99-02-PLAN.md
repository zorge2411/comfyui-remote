# Plan 99.2: App-scoped ModelDownloadRepository

## Objective

Move the model-download state out of `MainViewModel` into an app-scoped repository. The workflow screen, the Queue screen and the foreground service can then share one live view of the server's queue (99-CONTEXT D-01, D-03).

    `ComfyApiService`: add `moveModelDownload(@Path id, @Body JsonObject)`, `retryModelDownload(@Path id)` and `clearModelDownloads()`, all returning `Response<JsonElement>`.

    `ModelDownloadRepository(connection: ConnectionRepository, prefs: UserPreferencesRepository, okHttp: OkHttpClient)`:
    - uses its own `CoroutineScope(SupervisorJob() + Dispatchers.IO)`;
    - `api()` builds Retrofit from saved host, port and isSecure, as in `QueueViewModel.buildApiService`.

    State:
    - `helperAvailable: StateFlow<Boolean?>`, `helperVersion: StateFlow<Int>` (0 while unknown), `hasToken: StateFlow<Boolean>`;
    - `downloads: StateFlow<List<ModelDownload>>`;
    - `finishedEvents: SharedFlow<ModelDownload>`, emitted when a job changes to done;
    - `errors: SharedFlow<String>`.

    Behaviour:
    - `init` collects `connection.connectionState`. On CONNECTED it calls `refresh()`:
      - `getHelperInfo` sets available, version and token;
      - `getModelDownloads` replaces the list;
      - HTTP 404 means absent; other failures keep the previous value and log.
    - `init` also collects `connection.messages`:
      - `remote_helper.queue` → `parseList(data)` replaces the list;
      - `remote_helper.download` → upsert.
      - Detect changes to done by comparing with the previous list, and emit `finishedEvents`.
    - Actions (suspend or launched):
      - `probe(source)`;
      - `download(source)`: an optimistic queued row, with errors put on that row, as today;
      - `downloadAll(sources)`: sequential, in order, skipping sources that already have an active row;
      - `cancel(download)`;
      - `move(download, position)`, `retry(download)` and `clearFinished()`: only when `helperVersion >= 2`, otherwise no-ops.

    `ComfyApplication`: `val modelDownloadRepository by lazy { ModelDownloadRepository(connectionRepository, userPreferencesRepository, okHttpClient) }`.

    `MainViewModel`:
    - delete the Phase 97 state, `parseModelDownload`, `updateModelDownload`, `checkModelHelper` and the `remote_helper.download` branch;
    - expose `helperAvailable`, `helperHasToken`, `modelDownloads` and `helperVersion` from the repository;
    - `downloadModel`, `downloadAllModels`, `cancelModelDownload`, `probeModel` and `refreshModelHelper` delegate to it;
    - collect `finishedEvents`: `modelListCache.remove(dir)`, `fetchNodeMetadata()`, `_modelsVersion++`;
    - keep `missingModels` and `modelListCache`, still cleared on CONNECTED. Keep `settingsLoaded` for the other CONNECTED calls.

    `DynamicFormScreen`: use `domain.ModelDownload`, and look downloads up by key from the list.
