# Plan 100.1: Device Audit and UI Spec

## Objective

Confirm the code survey on the real device, find what only shows at run time, and write the conventions the rest of Milestone 5 follows. The user approves them before anything is built (100-CONTEXT D-02).

<task type="auto">
  <name>UI spec</name>
  <files>.gsd/phases/100/100-UI-SPEC.md (new)</files>
  <action>
    Write the conventions, each with a one-line reason and the component that implements it:
    - **Spacing:** `Dimens` tokens xs 4, s 8, m 12, l 16, xl 24; screen padding 16; list item gap 8; card inner padding 16.
    - **Top bars:** `AppTopBar` (M3 `TopAppBar`, titleLarge). Tabs have no back; pushed screens get the AutoMirrored back icon. Actions are icons with content descriptions, max 3, the rest in overflow.
    - **Section headers:** `SectionHeader`, titleSmall in the primary colour, with an optional trailing TextButton.
    - **Cards:** `AppCard`, default shape, inner 16, no custom elevation. Variants: Default (surfaceContainer) and Highlight (primaryContainer). Status goes in `StatusBanner`, not in cards.
    - **Status:** `StatusBanner(kind = Error | Warning | Info)` with a Material icon (ErrorOutline, WarningAmber, Info), title, optional message and actions. No emoji in UI text.
    - **Dialogs:** `ConfirmDialog`. TextButtons, dismiss on the left and confirm on the right. Destructive confirms use the error content colour. Every delete is confirmed.
    - **States:** `EmptyState` (scrolls), `LoadingIndicator` inline, `LoadingOverlay` over content using the theme scrim.
    - **Scrolling and landscape:** every full-screen form scrolls, with `imePadding` where fields can be under the keyboard.
    - **Colour:** theme roles only. Semantic connection status: connected is primary, connecting is tertiary, error is error, disconnected is outline. Media screens may use a black background.
    - **Touch targets:** 48 dp minimum.
    - **Insets:** edge-to-edge. Consume the outer Scaffold padding once; no hard-coded bar heights.
    - **Typography:** the M3 defaults. Screen titles come from the top bar, not headlineMedium Text.
  </action>
  <verify>The spec covers every inconsistency category in 100-AUDIT.md.</verify>
  <done>100-UI-SPEC.md is written.</done>
</task>
