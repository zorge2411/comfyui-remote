# Plan 101.2: Remembered Form Values

## Objective

Save each workflow's edited values and restore them when the workflow is reopened, with a reset to the workflow's defaults (101-CONTEXT decision 4, D-04).

  <files>app/src/main/java/com/example/comfyui_remote/MainViewModel.kt</files>
  <action>
    - `parseWorkflowInputs(workflow)` (keep a `json` overload if other callers need one) returns `FormValues.overlay(parsed, FormValues.decode(workflow.savedInputs))`.
    - `saveFormValues(workflow, inputs)`:
      - debounced: cancel any pending job, `delay(500)`;
      - then `repository.insert(current.copy(savedInputs = FormValues.encode(inputs)))`, using the latest entity from `selectedWorkflow` so other columns aren't overwritten;
      - skip workflows with `id == 0` (history previews).
    - `resetFormValues(workflow)`: `savedInputs = null`, then re-parse.

    AVOID: saving on every keystroke without the debounce, because every save rewrites the Room row.
  </action>
