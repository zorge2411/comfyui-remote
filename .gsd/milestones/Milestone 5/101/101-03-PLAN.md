# Plan 101.3: Form UI

## Objective

Rebuild `DynamicFormScreen` on the Phase 100 components and the 101.1/101.2 domain pieces:
- a fixed top bar;
- a status area at the top (warnings, progress, latest result);
- prompt, negative prompt and main settings with human labels;
- collapsed per-node sections;
- a fixed bottom action bar.

    - `MainSettings(fields)`: a `SectionHeader("Main settings")`, then pairs of number fields in a two-column `Row` (width/height, steps/cfg), then the rest full-width.
