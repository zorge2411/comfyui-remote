# Plan 102.3: Queue Tab, Offline Behaviour and Device Check

## Objective

- Make Queue the one place for everything waiting: the server's jobs, the app's local queue and model downloads, with no second bottom bar.
- Disable server actions with a reason while disconnected.
- Check the whole phase on the phone.
