# Plan 104.2: Gallery Grid, Filter Sheet and Saved Lists

## Objective

Bring the gallery grid, its filter and its saved lists onto the Phase 100 conventions, using the 104.1 data layer:
- a top bar with three actions;
- active filters shown as chips;
- confirmed Remove;
- Share and Save for selections;
- clear empty and error states;
- a single filter sheet;
- saved lists as named filters.
