# Plan 105.1: Navigation Rail and Haptics

## Objective

- In landscape the four tabs move to a navigation rail, freeing the height the labelled bottom bar takes (105-CONTEXT D-01).

  <name>Haptics helper, preference and Settings switch</name>
  <files>
    app/src/main/java/com/example/comfyui_remote/ui/components/Haptics.kt (new)

  </files>
  <action>
    - **Preference:**
      - `UserPreferencesRepository.vibration: Flow<Boolean>` (key `vibration`, default true) and `saveVibration`;
      - `MainViewModel.vibration: StateFlow<Boolean>` and `setVibration`.
    - **`Haptics.kt`:**
      - `class Haptics(view, enabled)` with `click()` and `confirm()`, plus `@Composable rememberHaptics(enabled)` using `LocalView.current`.
      - `click()`: `view.performHapticFeedback(HapticFeedbackConstants.CONTEXT_CLICK)`.
      - `confirm()`: `CONFIRM` on API 30+, otherwise `LONG_PRESS`.
      - Both do nothing when `enabled` is false. `performHapticFeedback` already follows the system touch-feedback setting.
    - **Form:**
      - `val haptics = rememberHaptics(vibration)`.
      - `haptics.click()` runs inside the actions that `withPreflight` runs: the Generate and the Queue action, once the run is actually sent (not when the pre-flight dialog opens).
      - Confirm: `var previous by remember { mutableStateOf(executionStatus) }` and `LaunchedEffect(executionStatus) { if (previous in (EXECUTING, QUEUED) && executionStatus == FINISHED) haptics.confirm(); previous = executionStatus }`.
    - **Settings:** under Appearance, a row "Vibration" with the supporting text "On Generate and when a run finishes" and a `Switch` (row `heightIn(min = Dimens.minTouch)`), in the same style as the auto-connect row.
  </action>
