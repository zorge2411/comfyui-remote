      - `Row(verticalAlignment = CenterVertically) { Box(Modifier.weight(1f)) { content() }; IconButton(onToggle) { … } }`;
      - icon: `Icons.Outlined.PushPin` (onSurfaceVariant) when not pinned; `Icons.Filled.PushPin` (primary) when pinned;
      - content description: "Pin <label>" or "Unpin <label>"; 48 dp by IconButton default.
    - **Pinned group:**
      - after `form.negative` (`:398`), when `form.pinned` isn't empty: `SectionHeader("Pinned")`, then each pinned field as `PinnableField(pinned = true) { renderField(it, Modifier) }`.
    - **Node sections:** `NodeSection`'s field lambda wraps each field in `PinnableField(pinned = false)`.
    - **Not pinnable:** the prompt, negative and Main settings get no pin.
    - **Pin action:** `viewModel.togglePin(workflow, lf.key)`.
    - **Expanded state:** the node group's expanded state is keyed by `nodeId`, so it's unaffected. A group emptied by pins simply disappears.
    - **Don't** change the per-field composables in `FormFields.kt`. The pin sits beside the field so it doesn't compete with their trailing icons.
