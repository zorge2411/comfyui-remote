# Plan 104.1: Filter, Remove and Metadata

## Objective

Build the data and domain pieces behind the new gallery:
- a local filter over the stored media, with sort;
- "Remove from gallery", which survives syncs;
- media metadata (prompt, seed, settings) read from the stored prompt;
- a sync error the UI can show.

All JVM-tested where possible (104-CONTEXT D-01 to D-04).
