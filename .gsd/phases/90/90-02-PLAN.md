# Plan 90.2: PrimitiveNode Values and SetNode/GetNode Pairs

## Objective

Resolve the two virtual nodes that carry data:
- **PrimitiveNode:** its value goes into each directly linked target widget (`applyToGraph`).
- **GetNode:** resolves by name to its SetNode's input.

This clears the last 3 corpus known failures, so `known-failures.json` becomes `{}`. It depends on 90.1: the virtual node set, the target-typed resolver, and the fallback to the saved value for unresolved widget links.
