# Plan 91.2: Pre-flight Before Queueing, and a Live Missing-Node Banner

## Objective

Run `PromptValidator` on the exact prompt about to be sent, before Generate and Add to Queue. Show the issues grouped by node, with "Queue anyway" and "Cancel". Make the "Missing Nodes on Server" banner reflect the connected server now, not the one used at import (D-04, D-05).

**Depends on**: Plan 91.1
