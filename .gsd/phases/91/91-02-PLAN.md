# Plan 91.2: Pre-flight in the Queue Paths

## Objective

Run `PreflightChecker` wherever the app sends or stores a prompt:
- **Generate:** a dialog before the batch loop, with one `/object_info` refetch.
- **Queue button:** at add time.
- **Background local-queue runner:** unchanged.

Expose the form-screen result for the card. No Compose code in this plan: 91.3 renders the state it exposes.

    1. **State.**
       - `data class PendingPreflight(val result: PreflightResult, val action: PreflightAction)`
       - `sealed interface PreflightAction`, with `Generate(workflow, inputs, batchCount)` and `AddToQueue(workflow, inputs, batchCount)`.
       - `private val _pendingPreflight = MutableStateFlow<PendingPreflight?>(null)`, exposed as a StateFlow.
       - `fun confirmPreflight()`: clear the state, then run the action with `skipPreflight = true`.
       - `fun cancelPreflight()`: clear the state and set the status back to IDLE.
    2. **Generate.** `executeWorkflow(workflow, inputs, batchCount, skipPreflight: Boolean = false)`.
       - After the uploads and before `repeat(batchCount)`: unless `skipPreflight`, and only when `_nodeMetadata.value` is non-null (D-07; otherwise log and continue), do the following.
       - Build `prepared = workflowExecutionService.prepare(workflow.jsonContent, uploadedFilenames, inputs)` using the un-randomised inputs, then run `PreflightChecker.check(prepared, meta, Options.queue(uploadedFilenames.values))`.
       - If there are issues, run `refreshNodeMetadata()` and, if it returns non-null, check again (D-06).
       - If issues remain: set `_pendingPreflight` to `Generate(...)`, set the status back to IDLE, and return.
       - Uploads that already happened are re-done on confirm. That is acceptable, since it's the same file and the server dedupes by name. Mention it in the summary. Don't add upload caching in this phase.
       - Remove the old `missingNodes` log warning (lines ~581–584), which this check replaces.
    3. **Queue button.** `addToQueue(workflow, inputs, batchCount, skipPreflight: Boolean = false)`: same flow, but with `prepare(workflow.jsonContent, emptyMap(), inputs)` and `Options.FORM`, since nothing is uploaded yet.
    4. **Form-screen result (D-05.1, RESEARCH §4).** Add `fun formPreflight(workflow: WorkflowEntity, inputs: List<InputField>): Flow<PreflightResult?>`, or a simpler suspend function the screen calls from a `LaunchedEffect`, whichever reads cleaner.

       - Otherwise it runs on `Dispatchers.Default`: `injectValues(jsonContent, inputs)`, then `PreflightChecker.check(..., Options.FORM)`.
       - No refetch here.
    5. **Missing-nodes column (D-12).** Leave the import code that fills `missingNodes` as it is. The only UI reader, the card in `DynamicFormScreen`, is removed in 91.3.
    Avoid:
    - blocking when metadata is missing;
    - checking once per batch item;
    - showing the dialog for an empty result.
