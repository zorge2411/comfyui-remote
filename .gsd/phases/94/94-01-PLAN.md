# Plan 94.1: Make the Corpus See Dynamic Combo Sub-Inputs

## Objective

`ApiPromptValidator` can't see sub-inputs of `COMFY_DYNAMICCOMBO_V3` that are missing or wrong, so the corpus understates this bug: SaveVideo fixtures pass while sending no `format.codec`. Extend the validator, add fixtures for the shapes the corpus lacks, and re-baseline. Plan 94.2's effect then shows up as known failures clearing (D-01).
